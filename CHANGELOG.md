## [0.1.0] - 2024-01-XX

### Added
- Initial release of Text2SQL framework
- Support for multiple base models (CodeLlama, Mistral, Phi-2, DeepSeek-Coder)
- LoRA and QLoRA fine-tuning implementations
- Dataset support for Spider, WikiSQL, BIRD, and CoSQL
- Comprehensive data preprocessing pipeline
- Custom trainer with SQL-specific callbacks
- Evaluation framework with multiple metrics
- REST API for inference
- Docker and Docker Compose configurations
- CI/CD pipelines for testing and linting
- Comprehensive test suite
- Example Jupyter notebooks
- Complete documentation
